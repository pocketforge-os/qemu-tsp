The harness verifies every immutable source, copies the raw SD image, checks
the byte-exact rootfs partition, and modifies only the disposable copy. It
rechecks the source image before boot and deletes the copy at exit. The kernel,
DTB and initrd are never modified.

Reproduction
------------

Build QEMU through patch 0022, then run inside the pinned qemu-test image:

  python3 tests/pocketforge-a133-build6-smoke.py \
    --qemu build/qemu-src/build-softmmu/qemu-system-aarch64 \
    --image build/smoke/Image \
    --dtb build/smoke/dtb.bin \
    --initrd build/smoke/initrd.gz \
    --sd build/smoke/Image.img \
    --work build/smoke/run

The smoke waits for the guest's systemd service stage. It records whether the
release image started `pf-input-decode.service` itself and starts that exact
unit only when inactive. On this run the unit was already active
(`decoder=auto`). The unrelated suspend path is masked on the QEMU-only kernel
command line. `pf-input-broker.service` is stopped only if active and restored
in the same invocation; it was inactive on this run.
